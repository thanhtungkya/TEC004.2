# Housing Market Dashboard

A starter Python project for scraping, cleaning, storing, and visualizing Vietnam housing market listings.

## Features
- Data collection modules for sample sources
- Cleaning and transformation utilities
- SQLite storage for property records
- Streamlit dashboard pages

## Quick start
1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python main.py`

The app will initialize the database and launch a simple dashboard entry point.
